# pymumble-rev

Asyncio Mumble client library. Distribution name `pymumble-rev`, import name `pymumble_rev`.

## Design rules

- `connection.py` is **sans-IO**: no sockets, no clocks, no threads, no asyncio. Callers pass time in
  (`ping(now)`), feed bytes in (`receive_data`), and take bytes out (`data_to_send`). Keep it that way;
  the asyncio transport (`client.py`) and audio pacing live outside it.
- `MumbleClient` owns exactly one connection and never reconnects; reconnecting is the caller's loop.
  Every write goes through `_flush()` (write + `drain()`), so backpressure suspends the sender rather
  than failing. Liveness is "any byte received within `dead_after`", fed by the ping task.
- Audio is pull-based: `AudioSender.run()` asks the current `AudioSource` for one frame per period on
  absolute deadlines, and resyncs instead of bursting after a stall. `AudioSource.read()` must never
  block (it runs on the loop); threads feed audio through `PcmBuffer`. libopus is bound with ctypes
  in `opus.py` and loaded lazily on the first `play()`, so text-only users never need it.
- State is immutable: `User`, `Channel`, `ServerInfo`, `ServerState` are frozen dataclasses. `Connection`
  mutates private dicts while handling one `receive_data` batch and publishes one new `ServerState` at the
  end (only when `_dirty`). Never hand out the private dicts.
- Per-entity events are suppressed until `Connected`; the initial sync lands in `state` only.
- Scope is deliberately small: client only, Opus tunnelled over TCP (`UDPTunnel` with the 1.5 protobuf
  audio format), Mumble 1.5+. No UDP/OCB2, no ACL editing, no positional audio. Don't add these without
  asking.
- Written from the Mumble protocol spec and `proto/*.proto`. Do not copy code from pymumble (GPLv3);
  this project is MIT.

## Generated code

`src/pymumble_rev/_proto/*` is generated by `scripts/gen_proto.py` from `proto/` (Mumble v1.5.939).
The script renames the protobuf package to `pymumble_rev.MumbleProto` so it can coexist with other
libraries that register `Mumble.proto` in the default descriptor pool. Never edit the generated files.
